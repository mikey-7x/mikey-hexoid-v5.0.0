## Where to ask

- **Bug reports:** open an issue using the bug-report form and include the details it asks
  for.
- **Feature ideas:** open an issue describing the workflow you want.
- **Commercial or industrial licensing:** use the commercial-licence issue form.
- **Author:** https://github.com/mikey-7x · https://github.com/mikey-7x?tab=repositories

## What this project does not provide

- Free commercial support, deployment help or paid integration — a separate written licence
  is required first.
- Guarantees that a specific board, core version or third-party library will build.
- Help bypassing the licence, the branding or the non-commercial restriction.
